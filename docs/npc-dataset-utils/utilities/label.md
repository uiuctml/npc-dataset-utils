# NPC Attribute Labeling Utility

The NPC Attribute Labeling Utility enables users to rapidly and efficiently create attribute labels for datasets came without any attribute labels.

The labeling utility is run as follows:

```bash
cd npc/npc-dataset-utils/src/npc-dataset-utils
./label.py
```

The labeling utility currently supports creating only class-wise, one-hot attribute labels.
